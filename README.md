# NetPractice

### 🎓 42 School – Final Grade: **100/100**

NetPractice is an interactive networking exercise from 42 designed to teach the fundamentals of:
- IP addressing  
- Subnetting  
- Routing  
- Understanding network topology  
- Troubleshooting incorrect configurations  

The project provides a browser-based interface where you must fix broken networks by assigning valid IPs, masks, and routes so every required link becomes reachable.

---

## 📦 What’s in this repository?

This repo contains solved configurations for all levels.

*(No code is written for this project — everything is done through the online interface.)*

---

## 🧠 What I learned

- How to split networks using subnet masks  
- How to determine host ranges, broadcast addresses, and gateways  
- Point-to-point addressing  
- Basic routing rules  
- Detecting and fixing unreachable networks
